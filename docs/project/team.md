## Organización del trabajo

**Repositorio:** `computing-laboratory/wellness-platform-team1`

**Flujo de trabajo:** rama `develop` → Pull Request → revisión → `main`

La rama `main` está protegida: toda integración requiere Pull Request revisado.

**Convención de commits:** prefijo `feat` o `fix` seguido de descripción en español.

```
feat: migrar RunCoach AI a estructura wellness-platform
fix: eliminar .DS_Store y agregarlo al .gitignore
```

## Continuidad entre asignaturas

La plataforma tiene origen en el proyecto desarrollado para **Ingeniería del Software y Bases de Datos**, donde se construyó la arquitectura cloud-native, los microservicios y el primer agente de IA.

En **Sistemas Inteligentes** esa plataforma evoluciona hacia un sistema basado en conocimiento: RAG en el Sprint 1, agentes inteligentes en el Sprint 2 y orquestación multiagente en el Sprint 3.
